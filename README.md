# ferosch - After Effects Extension

ferosch is a powerful After Effects extension that provides a suite of tools to enhance your workflow and productivity.

## Features

- **Layer Management**: Create solid layers, adjustment layers, null layers, and more
- **Ease Controls**: Easily adjust and apply easing to your animations
- **Text Tools**: Separate text by characters, words, or lines
- **Layer Offset**: Apply sequential or random offsets to multiple layers
- **Project Organization**: Organize your project files and compositions
- **Composition Tools**: Add info to compositions, crop compositions, and adjust settings

## Installation

### Requirements
- Adobe After Effects 2022 or newer

### Installation Steps

1. Download the `ferosch.zxp` file
2. Install using one of these methods:
   - **Adobe Exchange**: Double-click the ZXP file if you have Adobe Exchange installed
   - **ZXP Installer**: Use a third-party ZXP installer like [Anastasiy's Extension Manager](https://install.anastasiy.com/) or [ZXP Installer](https://zxpinstaller.com/)

## Usage

1. In After Effects, go to Window > Extensions > ferosch
2. The extension panel will open with all tools available

## Tabs and Features

### Layers Tab
- Create solid, adjustment, and null layers
- Trim layers based on keyframes
- Convert masks to layers
- Copy and paste ease values

### Project Tab
- Organize project files by type
- Add composition info (duration, date, resolution)
- Clean up unused layers

### Comp Settings Tab
- Adjust FPS and duration
- Crop compositions to content

### Text & Array Tab
- Separate text by characters, words, or lines
- Apply sequential or random offsets to layers
